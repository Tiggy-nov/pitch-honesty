# Changelog

## 1.2.0 — 2026-10-11

Attention-to-belief update based on Reece Chowdhry's Part 2.

- Reframed Phase B as **Detail / Belief**: attention is not enough; the investor must be able to underwrite why the company can work.
- Added the **Belief Engine**: Claim → Mechanism → Evidence → Implication.
- Added **proof density**: evidence should sit close to the claim it supports rather than being deferred to a generic traction slide.
- Added a six-level **evidence hierarchy** from founder assertion through compounding proof.
- Added the **Belief Gap Audit** to identify exactly what remains unsupported.
- Added a **coherence-under-questioning** test so deeper diligence strengthens rather than contradicts the opening narrative.
- Added **belief compression**: the investor must be able to state why the company can win and identify the strongest proof.
- Updated source provenance without attributing unverifiable article details to the author.
